# Roost Swift

The cryptographic core for private, end-to-end encrypted messaging in Swift apps.

## Usage

Add the package to your `Package.swift`, with the latest release's version:

```swift
.package(url: "https://github.com/chirp-org/roost-swift.git", exact: "X.Y.Z")
```

Add the product to your target's dependencies:

```swift
.product(name: "Roost", package: "roost-swift")
```
